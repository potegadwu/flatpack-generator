# Flatpack Generator

Social media post generator tailored for Flatpack, allowing users to customize text and backgrounds, scale/drag components, and preview/export posts for Instagram.

## Features
- Dynamic text editing with word-by-word font formatting (Bold/Italic) and custom coloring.
- Draggable items on canvas (Kicker, Title, Subtitle, Brand footer, Page number, and background image).
- Safe area margins (80px), 1:1 feed crop grid, and 3:4 profile grid overlays.
- Real-time preview matching Instagram's desktop layout.
- High-quality PNG export.

## Deployment
Deployed on Cloudflare Pages.
